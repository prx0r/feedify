# July 2026 Alpha Analysis

## Methodology

Following BEAR's approach: don't just count tweets. Classify what each tweet MEANS for our thesis.

**Thesis lens**: "What does increasing abundance make newly scarce?"

For each account, we ask:
1. Does this person identify a NEW bottleneck before the market sees it?
2. Does this person provide evidence of bottleneck migration?
3. Does this person own the "interface layer" between bits and atoms?
4. Does this person make falsifiable predictions we can track?
