## Account Properties for Feedify

Key property should not be `influence_score`. It should be:

```
source_distance:
  0 = personally running experiment / designing chip / training system
  1 = immediate collaborator
  2 = specialist observing field
  3 = analyst
  4 = journalist
  5 = influencer
```

Plus:

- `original_claim_rate`
- `mechanistic_claim_rate`
- `negative_result_rate`
- `prediction_rate`
- `falsifiability`
- `reply_signal`
- `promotion_ratio`
- `consensus_distance`
- `followers`
- `views_at_post_time`
- `claim_lead_time`

The killer metric is **claim lead time**:

Researcher says it at t₀ → evidence appears t₁ → corporate acknowledgement t₂ → market consensus t₃.

Next obscure statement from that researcher gets an enormous prior. That turns this from a Twitter recommendation engine into a learned information-propagation graph.

## Recursive Expansion

Don't stop at 100. Every time one of these accounts produces a high-information post, recursively crawl:
- Who they are replying to
- Who replied intelligently
- Paper coauthors
- GitHub contributors
- People thanked in acknowledgements

That is exactly how we keep moving downward from Levin → unknown developmental biologist → their PhD student → some 43-follower account mentioning the experimental artifact that eventually changes a billion-dollar thesis.
