# Tera Probe (6627.T) Reality Check: Can AI Do What Tera Probe Does?

## The Short Answer

**No. Tera Probe does physical semiconductor testing. AI can't test chips.**

## What Tera Probe Does

Tera Probe performs wafer-level and final testing of semiconductors. As chips get:
- More complex (HBM + 2.5D + SiPh)
- More expensive per package
- More failure modes

Testing becomes critical. One bad die caught late destroys the value of the entire package.

## Why AI Can't Replace This

1. **Physical test equipment** — You can't test chips with software
2. **Test program development** — Each chip requires custom test sequences
3. **Customer-specific calibration** — Each fab has unique requirements
4. **Yield data** — Proprietary yield information from testing

## The Moat

Tera Probe's moat is PHYSICAL:
- Specialized test equipment
- Test program expertise
- Yield data relationships
- Customer lock-in

## The Risk

1. **Japan listing** — Limits Western investor access
2. **Yen currency risk**
3. **Revenue still relatively small**

## Verdict

**AI cannot do what Tera Probe does.** Physical testing equipment.

**Confidence: 90%**
