## The Chain

```
GPU scarcity
→ advanced packaging
→ HBM yield
→ copper bandwidth wall
→ optics
→ laser/InP capacity
→ silicon photonics
→ electro-optical test/inspection
```

Each step exposes a more specialized constraint underneath it.

## The Key Insight

The thesis is NOT "AI → more electricity."

It is: **each solved constraint exposes a more specialized constraint underneath it.**

The market is currently moving through:
1. GPU scarcity (solved by ASICs)
2. Advanced packaging (CoWoS, HBM)
3. HBM yield (testing bottleneck)
4. Copper bandwidth wall (transition to optics)
5. Optics (laser capacity constraint)
6. Laser/InP capacity (MOCVD equipment bottleneck)
7. Silicon photonics (new packaging paradigm)
8. Electro-optical test (physical verification)

## The Alpha Thesis

> Own whatever makes increasingly complex physical computation verifiable and manufacturable.

**Generation cost ↓ while cost of being wrong ↑↑**

Therefore: **verification value ↑↑↑**
