# x402 deployment

Feedify includes an optional x402 v2 gate for `/api/paid/*`.

## Safe testnet setup

```bash
uv sync --extra x402
```

`.env`:

```dotenv
X402_ENABLED=true
X402_PAY_TO=0xYOUR_TESTNET_ADDRESS
X402_NETWORK=eip155:84532
X402_FACILITATOR_URL=https://x402.org/facilitator
X402_PRICE_USD=0.01
```

Then:

```text
GET /api/paid/feeds/agent-commerce-alpha.json
```

will be protected by the official FastAPI x402 v2 middleware.

The implementation follows the current Python v2 pattern: `HTTPFacilitatorClient`, `x402ResourceServer`, `ExactEvmServerScheme`, `RouteConfig`, `PaymentOption`, and `PaymentMiddlewareASGI`.

## Production

- Use a dedicated receiving address.
- Configure a facilitator appropriate for the selected mainnet.
- Do not place a funded wallet private key in the Feedify server; a seller only needs its receiving address for the exact server flow.
- Add per-feed price metadata before turning on creator monetization.
- Attach source-license restrictions to feeds; paid redistribution may be prohibited by an upstream provider even if personal derivation is allowed.
